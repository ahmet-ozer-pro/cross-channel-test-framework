@cross-channel
Feature: Çoklu evrak cross-channel yaşam döngüsü

  API ile üretilen birden çok evrakın HEPSİ web listesinde görünebilmeli.
  Koleksiyon store (push/getAll) ile chaining: API üretir, Web hepsini doğrular.

  Scenario: API'de üretilen tüm evraklar web listesinde görünür
    Given API üzerinden 3 yeni gelen evrak oluşturulmuştur
    When web kanalında evrak listesi açılır
    Then API'de oluşturulan tüm evraklar web listesinde görünür
